# Goudse Kaas – installeerbare web-app

Deze map is een complete offline web-app (PWA). Die moet via **https** te bereiken zijn, alleen dan kan de iPhone hem als app installeren.

## Snelste manier: GitHub Pages
1. Maak een repository aan (bijv. `mulder-design-automation/goudse-kaas`) en zet deze bestanden erin.
2. Ga naar Settings → Pages → Source: `main` / root.
3. Open de URL op je iPhone in **Safari** → deelknop → **Zet op beginscherm**.

## Wat de geïnstalleerde versie extra kan
- Werkt volledig offline (ook in de kaasruimte zonder bereik).
- Lange wachttijden (persen, verzuren, pekelen) en de rijpingsplanning direct in je iPhone-agenda zetten (📅-knoppen), met een melding.
- Gegevens worden op de iPhone zelf bewaard. Maak via Instellingen af en toe een back-up (.json).

Let op: iOS pauzeert web-apps op de achtergrond. Zet voor korte timers het scherm aan met de knop "Scherm aan", of zet lange stappen in je agenda.
